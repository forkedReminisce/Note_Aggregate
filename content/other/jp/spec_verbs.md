Irregular verbs are those that don't exactly follow the normal verb conjugation rules. There are also some verbs that require an in-depth analysis.



# {{< heading "\"To Do\"" >}}
**する** is an irregular verb. The conjugations are like ==an ichidan verb but す～ becomes し～==. 

{{< subtext >}}
    The basic non-past conjugation is just する.
{{< /subtext >}}

する has **many translations**. For the most part, it is a transitive verb. The direct object could be another verb, an activity, wearable accessory, trait, or occupation.

<!-- TODO: is this necessary to talk about -->
{{< subtext >}}
    When describing one's occupation, する becomes している.
{{< /subtext >}}

"To sense" applies to the five senses or emotion. "To cost" is used by the customer, and the price precedes する. Finally, for particular nouns, する can be attached to turn it into a verb.



# {{< heading "\"To Come\"" >}}
**来る** is another irregular verb. However, ==the irregularities apply to the pronunciation==. Again, the conjugations are very similar to those of the ichidan class.

<!-- TODO: can the person "coming" ever use 来る? -->
来る solely means "**to come**." Both spatial and temporal contexts are applicable. The destination is the current state of the speaker's—literally or what they're currently thinking.

# {{< heading "Existential Verbs" >}}
There are two existential verbs. **ある** is a godan verb with irregular conjugations for the negative: ない and なかった. **いる** is a normal ichidan verb.

As **existential verbs**, ある is for *inanimate objects*, whereas いる is the opposite. In fact, ==いる is so emphatic about the object== that it is paired with emotionally-attached dead beings. This verb can also personify, and it suggests movement now or surrounding time. In any case, if also specifying location, existential verbs are only valid if the object naturally occurs there or it is obvious how it got there.

{{< subtext >}}
    いる has an added definition meaning "**to live** (at)." This is an intransitive verb, so use に.
{{< /subtext >}}

{{% example_jp 
    jp="「あそこにバスが**いる**」"
    en="\"***There is** a bus over there **(that is moving or had finished for the day)***.\""
%}}
