Note Aggregate is a collection of personal notes for various UT Austin 
courses. Japanese is also there.



# Dependencies
- [Standard Hugo](https://gohugo.io/): building the site
- [Dart Sass](https://sass-lang.com/dart-sass/): transpile Sass to CSS
- [Pagefind](https://pagefind.app/): enable searching



# Build
Clone this repo and run `pagefind` in the directory. Then run `hugo server`.
