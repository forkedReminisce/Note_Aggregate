Compound verbs are created by taking the polite form of the main verb and replacing the ～ます with secondary verb. This secondary verb holds the conjugation function.



# {{< heading "Initiation" >}}
<!-- ～出す and ～出る dont necessarily want attention; sometimes just exposing the action to a larger audience -->
～始める focuses on the initiation of the main action. ～出す essentially ever so slightly demands attention for the main verb. Sometimes, ～出す is replaced with ～出る. The former is more dramatic, indicates directionality, or allow the compound verb to be used as a noun as ～出し. All these are nuances ～出る doesn't have; it just brings attention to the main action. 

{{% example_jp
    jp="「涙が瞼から**流れ出した**。」"
    en="\"*Tears streamed out from my eyes*.\""
%}}

<!-- instantaneous main verbs can be used with the first nuance of ～出す -->
～出る can be the only option if ～出す may be mistakened for its other use. In this case, if the main verb is transitive, ～出 can make the compound verb a noun. This other use of ～出す is essentially the dramatic equivalent of ～始める. Another difference is that ～始める highlights volition, whereas ～出す doesn't exactly allow for the agent's control over the main action. Additionally, both cannot be used with instantaneous main verbs, unless the main action happens repeatedly such that a beginning can be marked. Some compound verbs can support either ～出す, and a good indicator is whether the context allows for instantaneous action (first nuance) or the action takes some time for there to even be a beginning (second nuance).

{{< subtext >}}
    ～出し始める is possible when ～出す is using its first nuance.
{{< /subtext >}}

{{% example_jp
    jp="「食べ**始めて**ください。」"
    en="\"*Please start eating*.\""
%}}
